# 待机功耗控制（Idle Power Control）

ColorOS 15 / 16 / 17 通用的 LSPosed 熄屏省电模块，**不是一加 13 专用**。一加、OPPO、realme 的 ColorOS / RealmeUI 机型都可以直接用，Android 13+ 的其他机型多数也能运行（用到 OPPO 系服务的部分功能会按机型自动降级）。

已在以下机型实测：

- 一加 13（PJZ110，ColorOS 16 / Android 16）
- OPPO Find X8 Ultra（PKJ110，Android 17）
- OPPO Find N3 典藏版
- OPPO Find X9（PLG110，ColorOS 17 / Android 17，天玑平台）—— 目前只有诊断模式基线（熄屏 112 分钟掉 1%，约 0.5%/h），省电档还没复测
- 一加 15（PYF110，ColorOS 17 / Android 17）—— 目前只有亮屏段样本，熄屏数据还在等

## 它做什么

- **熄屏接管唤醒锁**：按预设清单拦掉闹钟、广播、部分唤醒锁，限制第三方应用靠定时唤醒把系统叫醒
- **闹钟限流**：`ALARM_RATE=N` 让每个包每分钟最多调度 N 个闹钟，超了直接丢。微信 / QQ 那种熄屏后一分钟排几十次闹钟的，这是整夜掉电的主因；极致省电档默认 4 次/分，代价是消息可能延迟
- **强制深睡**：熄屏一段时间后直接 force-idle，让系统进入 Doze 深睡，而不是原地待机
- **三档预设**：正常（3 条规则）/ 省电（13 条）/ 极致省电（19 条），可自己改 `BLOCK=` 清单
- **流量省电**：关闭 / 温和 / 彻底三档。温和档开系统数据省电并把微信、企业微信、QQ、短信加入白名单；彻底档熄屏即断移动数据，每 15 分钟开 20 秒窗口收消息。连 Wi-Fi 时不干预，亮屏立刻恢复
- **插电不接管**：插着电熄屏时不做深睡、不强停应用、不断移动数据（系统本来就不让插电进 Doze），拔电后条件满足会自动接上
- **使用统计**：亮屏 / 熄屏时长与掉电分开计，时长按进行中的那一段实时累计；口径默认是「上次充满电后」，充满自动清零（可关，`FULL_RESET=1`），也能手动「重置统计」，卡片上写明这一次是从充满电、手动重置还是开机算起
- **功耗曲线**：每分钟采样一次电池节点，画成功率（mW）与温度曲线，只保留最近 24 小时，双指缩放、双指拖动；点「区间统计」后可在曲线上拉出一段，看这一段自己的平均功率、温度、亮熄屏时长与掉电
- **唤醒榜**：本次息屏期间各应用唤醒次数排行，一眼看出谁在偷偷耗电
- **数据只在本地**：模块运行数据写在 `/data/system/idlepower.*`，不上传；App 只在打开时读取公告和远端状态

## 安装

1. 手机需要 root（Magisk / KernelSU / APatch）和 LSPosed
2. 安装本模块 APK，在 LSPosed 里启用，**作用域只勾「系统框架」**，然后重启手机
3. 打开 App，首次会请求 root，点允许并勾选「记住选择」
4. 进「功能」页选预设，「设置」页可单独调采样频率、息屏延迟、流量省电档位

升级模块后必须重启一次，新版本才会真正注入（不重启会继续跑内存里的旧模块）。

## 版本

当前 **v8.9（versionCode 251）**

这一版主要是发布前的收口和稳定性修复：

- 版本号升到 8.9；「清空曲线」只清 App 内显示，`idlepower.hist` 原文件保留、不删，新采的点从清空那一刻接着画，不提供恢复旧曲线
- 统计页去掉采样点数量文案；修好「充满清空曲线」开关的读写
- 曲线区间：点「区间统计」后在曲线上按住拖出一段，显示这一段的熄屏待机功率、温度均值、亮屏/熄屏时长和掉电；选完自动锁定并放大，单指扫点、双指平移缩放；「重新选择区间」只在选好区间后出现，退出区间自动隐藏；退出后再进来能重新拖，也能用「选开始时间 / 选结束时间」直接定时段
- 预设清理：删掉 `com.heytap.mcs:*job*`、`com.oplus.battery:*` 等无效或容易误伤的规则，撤回试加的 `com.oplus.subsys`，省电/极致回到干净状态
- 唤醒榜窗口改为从息屏那一刻起算、亮屏那一刻封存，去掉「记录于」尾巴
- 息屏汇总只统计放电点、跳过插电点；充电时不再算出「平均 -16360mW」这种假账；没有有效采样时写「无采样」
- 补 realme 等机型的充电识别：USB 在线路径读不到时，`Charging/Full` 状态按插电兜底，避免充电中强推深睡
- 省电白名单只在息屏延迟后收紧，亮屏时恢复原样；不足 1 分钟的息屏不写 `# SESS`
- 心跳增加 `code=`；8.9 同名旧模块没重启时，首页会提示「内存模块不一致」，不用再靠猜
- 修掉统计上报和状态回退里写死的 `8.0` 版本号，统一读当前版本
- 更新日志里的远程控制条目已经删除；App 内不再展示相关内容

升级后必须重启一次，否则 system_server 里仍是旧模块的代码。

## 反馈：欢迎把诊断报告发给我

模块的省电效果高度依赖机型和 ROM，**很需要真实机器的数据来继续优化**。

导出方法：App「关于」页 →「一键诊断 / 导出报告」，会生成一个 `待机功耗控制-报告-MMDD-HHMM.txt`，里面是配置、模块心跳、运行日志和系统诊断（`dumpsys` 片段）。

发给我：酷安私信或评论区 **@污黄瓜地**，或者在 GitHub Issues 里贴上来。

发之前顺手说明几点，定位会快很多：

- 机型 + ROM 版本 + Android 版本
- 当时用的预设（正常 / 省电 / 极致省电）和流量省电档位
- 熄屏时是否连着 Wi-Fi、后台留了哪些应用、有没有放歌或导航
- 大致现象：掉电百分比、熄屏时长、想解决的具体问题

报告里没有账号、手机号、位置这类个人信息，只有功耗相关的系统输出，可以放心发。有了不同机型、不同 ROM 的报告，才能把规则清单和深睡策略继续调准。
