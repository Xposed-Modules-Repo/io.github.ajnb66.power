# 待机功耗控制

ColorOS 15 / 16 / 17 通用的 LSPosed 熄屏省电模块，一加、OPPO、realme 均适用，**不是一加 13 专用**。

已实测机型：一加 13（PJZ110）、OPPO Find X8 Ultra、OPPO Find N3 典藏版。同代 ColorOS / OxygenOS 机型理论上都能跑，未逐一实测。

## 功能

- 熄屏后按预设清理后台唤醒锁、强制进入 Doze 深睡，亮屏自动解除
- 三档预设：正常 / 省电 / 极致省电
- 内核与部分唤醒锁排行，看得到谁在耗电
- 功率与温度曲线：最近 24 小时，双指缩放、拖动平移
- 流量省电：只用移动数据时接管熄屏网络，温和档开数据省电并放行微信 / 企业微信 / QQ / 短信，彻底档熄屏断数据、每 15 分钟开 20 秒窗口收消息；连 Wi-Fi 不干预
- 主题：经典 / 清爽蓝 / MIUIX 三套风格，每套都有日间与夜间
- 所有数据只写本机 /data/system，不上传、不联网（仅拉取公告时访问网络）

## 安装

1. 安装 APK，在 LSPosed 中启用本模块，作用域勾选「系统框架」。
2. 重启手机生效。
3. 打开 App 按提示授予 root，模块会写入 /data/system/idlepower.conf，参数 3 秒内热生效。
