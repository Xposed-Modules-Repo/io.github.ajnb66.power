# 待机功耗控制

OnePlus 13（ColorOS 15 / 16 / 17）的熄屏省电模块。

- 熄屏后按预设清理后台唤醒锁、强制进入 Doze 深睡
- 拦截闹钟与后台广播，三档预设：轻度 / 标准 / 极致
- 内核与部分唤醒锁排行，看得到谁在耗电
- 功率与温度曲线统计，只保留最近 24 小时，可双指缩放、左右平移
- 所有数据只写本机 /data/system，不上传，不联网

安装后到 LSPosed 启用本模块，作用域勾选「系统框架」，重启生效。

作者：污黄瓜地（酷安 @污黄瓜地）
版本：v8.0（versionCode 171）
